# KnowGrove Support

KnowGrove is a local, recoverable voice recorder for iPhone.

For support, open an issue at:

https://github.com/lufie/KnowGrove-iOS-Support/issues

Please include the KnowGrove version, iOS version, device model, and a short description of the problem. Do not attach private recordings or sensitive captured content.

---

# 言续支持

言续是一款面向 iPhone 的本地可恢复录音工具。

如需支持，请在以下地址提交问题：

https://github.com/lufie/KnowGrove-iOS-Support/issues

请附上言续版本、iOS 版本、设备型号和问题简述。请勿上传私人录音或敏感的收集内容。
